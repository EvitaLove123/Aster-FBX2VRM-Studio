3. Humanoid & finger mapping

Map bones before exporting. VRM export requires the core humanoid bones; review Auto-Mapping before downloading.

4. Material editor

Material preview controls are included in the VRM-exporter pipeline. VRM 0.x writes materialProperties (MToon or Unlit); VRM 1.0 writes VRMC_materials_mtoon or KHR_materials_unlit. Texture channels are carried when supported by glTF.

Choose a material, texture channel and image, then apply it.

5. VRM metadata

Model name and author are required for both export formats. Choose permissions carefully; they are written into the exported VRM metadata.

No thumbnail selected.

6. VRM export

Uses the shared Aster VRM-exporter modules: GLTF serialization, VRM 0.x / 1.0 metadata, Humanoid node references, MToon / Unlit material extensions, thumbnail embedding and three-vrm read-back validation. VRM 0.x also writes the standalone root-level secondary node; SpringBone and collider groups remain empty in this FBX edition.

Large source textures are resized during export. This can reduce VRM size and app loading time, but may reduce texture detail.

Load a model and complete required humanoid mapping to export.

7. Prototype status

  • FBX file selection and local ArrayBuffer parsing
  • External image selection with filename-based URL matching, including reloading after textures are added
  • Mesh visibility recovery and double-sided material preview
  • Experimental Auto T-pose for recognized upper-arm, forearm, and hand bones
  • Three.js 3D scene with lighting, grid, axes, and responsive resize
  • Orbit, zoom, pan, automatic framing, and camera reset
  • Basic mesh, material, and skeleton inspection
  • Manual material texture assignment for base color, normal, roughness, metallic, emissive, alpha and ambient occlusion
  • Improved scored Humanoid and Finger Auto Mapping with unique bone assignment and missing-bone report
  • Shared VRM-exporter modules for VRM 0.x and VRM 1.0 with three-vrm read-back validation
  • VRM 0.x metadata, MToon / Unlit materialProperties, thumbnail embedding and standalone secondary root node
  • VRM 1.0 metadata, MToon / Unlit material extensions and thumbnail embedding

FBX input and bone mapping are handled by this studio; the shared VRM-exporter modules serialize VRM 0.x / 1.0 and read the result back through Pixiv three-vrm. VRM 0.x writes the separate root-level secondary node. Validate every model in your target apps.
